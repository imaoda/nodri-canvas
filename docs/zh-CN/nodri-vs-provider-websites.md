# Nodri 和直接使用即梦、小云雀网页有什么区别？

[English](../nodri-vs-provider-websites.md) · [Nodri 介绍](../../README.zh-CN.md)

适用版本：Nodri v0.1.1 · 文档核对日期：2026-10-19

Nodri 提供本地画布，用来集中组织多个账号的 AI 图像与视频创作，把参考素材、提示词、分镜和镜头片段放在一起。生成仍由所选平台处理，使用该平台账号的权限和积分。

## 创作流程有什么变化？

| 要做的事 | 使用 Nodri | 直接使用平台网页 |
| --- | --- | --- |
| 整理项目 | 在本地画布排列导入的参考和生成结果 | 使用平台工作区，并自行组织文件 |
| 跨平台复用参考 | 用连线或 `@` 选择素材，前提是目标模型接受该输入 | 自行在服务之间转移或上传素材 |
| 选择账号 | 添加账号后，在顶部工具栏切换 | 使用各平台的账号操作入口 |
| 选择生成参数 | 在节点中选择模型及其可用参数 | 使用平台自己的界面与功能 |
| 保存画布生成结果 | 下载到本地项目目录 | 按平台流程下载和管理 |
| 支付生成费用 | 各账号独立计算积分、遵循平台规则 | 各账号独立计算积分、遵循平台规则 |

Nodri 的接入范围见[平台与模型支持表](./supported-models.md)。接入某个平台不代表覆盖其网页的全部功能与模型。

## 示例：把同一镜头的两版结果留在一起

导入角色图和房间图，创建图像节点，通过连线或 `@` 选择参考，生成分镜。再创建视频节点，引用选中的分镜图。提交前从工具栏选择账号，在节点中选择模型并检查参数。

想换平台尝试下一版时，切换当前账号，检查下一节点的模型与输入要求后提交。参考图和不同版本的镜头片段可以并排保留；已提交的任务仍使用原账号。

完整步骤见[即梦与小云雀同画布工作流](./jimeng-xiaoyunque-workflow.md)。

## 适合怎么选？

如果要为多个镜头反复使用角色、场景，或在多个平台账号之间创作，Nodri 的画布有助于把相关内容放在一起。只做一次生成，或需要平台自身界面中的专属功能时，直接使用网页可能步骤更少。

连线不代表自动执行整张图，画布也不会把镜头自动剪辑成片。参考图有助于约束生成，不保证角色完全一致。

本地保存不等于离线推理或素材不上传：生成需要在线平台和有效账号，所需参考会发送到所选平台。Nodri 是独立工具，并非上述平台的官方客户端；提及名称不代表合作或背书。
