# AI 短剧素材怎么管理：角色、场景、分镜与结果

[首页](../../README.zh-CN.md) · [English](../short-drama-assets.md)

Nodri 可以把可复用的角色图、场景图与分镜、视频结果放在同一画布。导入素材会复制到本地项目，生成结果也会下载到项目里。通过连线或输入框 `@` 继续引用，减少下一次生成时反复找文件、手动上传。

适用 **Nodri v0.1.1**，核对日期 **2026-10-19**。

## 按创作用途布置画布

新建项目，拖入参考图。可以从左到右排列四个区域：

| 区域 | 放什么 | 回答什么问题 |
| --- | --- | --- |
| 角色 | 已选定的外貌、服装参考 | 这个镜头里是谁？ |
| 场景 | 地点与光线参考 | 故事发生在哪里？ |
| 分镜 | 各镜头的静帧构图 | 画面怎么拍？ |
| 结果 | 靠近对应输入的视频片段 | 哪个结果可以用？ |

这是建议的摆放方式，不是自动目录或时间线。拖动节点整理位置，用文本节点记录镜头说明。

## 每个镜头留一份简短说明

记录镜头编号、人物动作和景别，把相关参考放在附近，再新建图像或视频节点。只为它连接需要的素材，或在生成输入框中用 `@` 选择。

镜头说明示例：

> 02 号镜头：雨天咖啡馆，中景。使用所选角色图的外貌与服装，采用咖啡馆图的环境。人物打开红色信封，发现意料之外的内容。背景保持简洁。

示例只是提示词；素材仍须通过连线或 `@` 真正选中。

检查当前生成账号，选择节点的模型，确认参数后提交。即梦、小云雀、LibTV 的模型范围不同，安排工作流前先看[平台与模型支持表](supported-models.md)。

## 检查结果，再继续引用

1. 等生成完成并下载到本地后，再把结果作为参考。
2. 对照镜头说明，检查人物、构图和动作。
3. 把可用结果留在相关参考旁。制作下一镜头时新建节点，重新明确选择参考。
4. 想把新尝试和旧结果并排比较时，先另建一个节点再提交。

移动导入前的原文件不会影响已导入素材。保持项目与其受管文件完整。

## 限制与下一步

画布整理方便人工检查连续性，不保证角色一致，也不会自动剪辑成完整短剧。不同模型的参考类型与数量限制不同，生成会把所选参考传至在线平台，并遵循其账号规则。

选定片段后，在视频剪辑软件中完成组装。继续查看 [Seedance 图生视频教程](seedance-image-to-video.md)，或[即梦与小云雀工作流](jimeng-xiaoyunque-workflow.md)。
