# 如何在同一画布中使用即梦和小云雀生成视频

[English](../jimeng-xiaoyunque-workflow.md) · [Nodri 介绍](../../README.zh-CN.md)

适用版本：Nodri v0.1.1 · 文档核对日期：2026-10-19

Nodri 可以连接即梦和小云雀账号，把两个平台的图片、分镜和视频片段放进同一本地项目，并继续复用为生成参考。账号从顶部工具栏选择，模型在各节点中选择；积分和模型权限仍属于各平台账号。

## 添加两个平台的账号

1. 新建项目，打开「设置 → 账号管理」。
2. 在账号页点击「添加账号」，选择即梦或小云雀，在登录窗口中完成登录。重复操作添加另一个平台。
3. 回到画布，从工具栏账号菜单中选择下一次提交使用的账号。

切换只影响后续提交，已提交的任务继续使用原账号。模型范围见[平台与模型支持表](./supported-models.md)。

## 示例：角色参考图 → 分镜图 → 视频镜头

准备一张有权使用的角色图和一张场景图。

1. 把两张图拖入画布，文件会复制到本地项目中。
2. 选择即梦账号，双击画布空白处创建图像节点。将参考图连到该节点，或在生成输入框键入 `@`，从候选项中选择参考节点。
3. 选择图像模型及可用参数，填写提示词，例如：“竖屏中景，参考角色站在参考房间的门口，看向镜头。”提交后检查分镜图。
4. 切换到小云雀账号，创建视频节点，用连线或 `@` 引用选中的分镜图。选择可用的视频模型，描述一个简单动作，例如：“人物慢慢转头看向窗外，固定镜头。”确认模型的参考要求、时长等参数后提交。
5. 检查镜头片段。素材与结果留在一起，方便调整；画布生成结果会下载到本地项目。

当目标模型接受该类输入时，同一素材可以跨平台复用。参考图有助于约束生成，但不保证角色和动作完全一致。

## 适用场景与限制

- 适合跨账号整理角色参考、分镜和镜头片段。连线不代表自动执行整张图，画布也不会自动把片段剪辑成片。
- 生成依赖在线平台和有效账号。积分不会合并或跨账号转移，权限与费用遵循平台规则。
- 本地保存不等于离线推理，也不等于参考素材不上传；生成所需素材会按需发送到所选平台。
- Nodri 是独立工具，并非即梦或小云雀的官方客户端；提及平台名称不代表合作或背书。
