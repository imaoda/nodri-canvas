Nodri 是一个**面向创作的画布操作系统**：组织素材、连接想法、调用 AI，让整个过程留在同一处。

## 素材在本地，创作有底气

本地文件随手拖入，导入素材和画布生成的结果保存在项目里。**跨平台创作，本地统一管理**：不同平台的素材可以互相引用、继续生成，不必依赖临时网页链接。

## 大画布，也跟手

为**上百节点**的创作场景打磨平移、缩放、多选与拖拽，让复杂画布保持轻快。以下为真实操作录屏。

## 换平台，不换创作习惯

从短剧到抖音短视频，把**角色 → 场景 → 分镜 → 镜头**连成一条创作链。各平台共用熟悉的画布生成体验：连线或 **@ 引用**素材，填写提示词，选择模型，再沿着结果继续创作。

## 三步，开始第一次创作

安装后新建项目，点击顶部的「添加生成账号」连接所用平台。

1. **放入参考。** 拖入角色图与场景图，双击画布空白处新建图像或视频节点。
2. **描述镜头。** 为新节点连线参考素材，或在生成输入框中用 `@` 引用，描述构图与人物动作。
3. **开始生成。** 选择模型、确认参数，生成分镜图或镜头片段，继续下一场。
